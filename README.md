# Cougar Advising - CPS 5981 Unit 10 laboratory target

**Deliberately vulnerable. Never deploy it.** It runs only inside your own
GitHub Actions runner, bound to `localhost`.

This repository is the starting point for **Lab 10 - Continuous Security
Validation (20 points)**. Follow the clickable lab page your instructor shared;
everything is done in the browser on github.com. Nothing to install.

| Path | What it is |
|---|---|
| `app/` | The application under test |
| `security-tests/` | Your security tests (one worked example is provided) |
| `gate-policy.md` | The policy the gate enforces - the starter version blocks nothing |
| `gate/evaluate.js` | Applies the policy to the raw scanner output (do not edit) |
| `.github/workflows/security.yml` | The pipeline: secrets, SCA, SAST, security tests, DAST, gate |
| `run-output/`, `dast/` | Where you commit the raw evidence downloaded from your cited runs |
| `pipeline-run.md` | You create this - the run record (generated by the lab page) |

A green run is not evidence of assurance. It is evidence that these checks did not fire.
